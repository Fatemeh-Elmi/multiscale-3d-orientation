SOURCE CODE REVISION 1.0.1 — VALIDATION STATUS
=================================================

This is a correction to the supplied 1.0.0 release. The multiscale estimator,
phantom generation, and experimental candidate-region estimator are unchanged.

 Helix spread versus fusion error: rho=1.000, n=6, p=0.00277778

The eight prescribed tortuosity wavelength/amplitude settings include
TWO physically identical straight geometries (amplitude A=0) and are therefore
collapsed to seven distinct geometric conditions for the inferential analysis.
The eight-setting descriptive statistic is separately retained in code outputs.

Statistical tests should not be interpreted as evidence of generalization beyond
the prescribed phantom designs. Real-data voxel-wise absolute accuracy cannot
be determined without independent ground truth.

Reference experimental values remain those reported in the 1.0.0 source
archive; raw NRRD data are NOT bundled with this release. Verify against the
original NRRDs using `python verify_reference_results.py --data-dir ...`.

To regenerate synthetic checks, see README.md. The code revision does NOT
introduce a direct benchmark against Fourier, ray casting or other independent
orientation-estimation algorithms.
