# Release v1.0.0

GitHub-ready source release for the manuscript's confidence-weighted multiscale 3-D orientation framework.

Included:
- core 3-D structure-tensor implementation
- baseline synthetic validation
- extended synthetic validation covering radius, crossing angle, tortuosity, and bundle dispersion
- geometry-derived ground-truth evaluation for synthetic phantoms
- experimental P86 candidate-region workflow
- four-volume experimental runner
- Figure 9 generator
- manuscript-result verification script
- README, requirements, validation report, self-check, and SHA-256 checksums

Important:
- Experimental NRRD data are not bundled.
- P86 is used only for experimental candidate-region selection, not for synthetic ground-truth masks.
- No license is bundled; choose and add the repository license before making the release public.
